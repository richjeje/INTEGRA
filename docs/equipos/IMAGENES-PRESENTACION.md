## Criterio de restauración

Se utilizó edición generativa integrada con el caso `precise-object-edit`. El prompt base pidió conservar encuadre, perspectiva, trayectoria del transportador, geometría estructural, posición de componentes, arquitectura y elementos de seguridad. La intervención corrigió resolución, exposición, balance de color, ruido, artefactos JPEG y claridad de bordes. También pidió evitar maquinaria nueva, textos, logotipos inventados, personas añadidas, HDR excesivo, apariencia CGI y marcas de agua.

Las restauraciones reconstruyen detalle que no existe en los archivos comprimidos. Por eso deben tratarse como imágenes ilustrativas y no como evidencia dimensional, documental o de configuración exacta. Los originales permiten comparar cualquier detalle dudoso.

## Recursos que no se restauraron con IA

- Logotipos de Integra y de clientes: deben obtenerse como archivos oficiales para evitar deformaciones.
- Planos, cotas y despieces de las diapositivas 15, 17 y 19: la reconstrucción generativa podría modificar medidas o componentes.
- Fotografías repetidas o de baja utilidad para la landing.
- Imágenes con marcas de cliente incrustadas cuando existe una alternativa limpia.
